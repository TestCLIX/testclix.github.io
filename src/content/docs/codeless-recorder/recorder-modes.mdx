The status badge in the toolbar above the [Live Screen](/codeless-recorder/live-screen) tells you how the recorder currently responds to input. Its label and colour change automatically as you record, preview, or replay a scenario.

The header separately shows whether you are **Recording** a new scenario or **Editing** an existing one.

## Status indicators

### Connecting

Shown while TestCLIX establishes the remote browser connection and waits for the first live frame. Recording actions are unavailable until the connection is ready.

### Live (focused)

<img src={liveImg.src} alt="Live status badge showing that the recorder is ready for input" />

The main recording state. A green **Live** badge means that the remote browser is ready and scenario steps are being captured.

In this state you can:

- Interact with the page - click, type, scroll, and select values.
- Add a [Mouse Hover](/codeless-recorder/mouse-hover) step.
- Add verification steps such as [Compare Screen Fragment](/codeless-recorder/image-checker), [AI Assistant](/codeless-recorder/ai-assistant), or [Screenshots](/codeless-recorder/screenshots).
- Add a [Text Checker](/codeless-recorder/text-checker).
- Add [pauses](/codeless-recorder/pauses) and [masked fields](/codeless-recorder/masked-fields).
- Run [Replay and Regenerate](/codeless-recorder/replay-and-regenerate).
- Review and remove events in the [Session Timeline](/codeless-recorder/session-timeline).

While in Live, the recorder can temporarily switch how the canvas handles input:

- **Recorder** (default) - clicks, typing, selections, and scrolling are captured as timeline events.
- **Hover** - records a pointer position without clicking.
- **Text Checker** - selects an element and captures the text that should be verified.
- **Selection** - lets you draw a region for Compare Screen Fragment, AI Assistant, or Movie Checker.
- **Inspect** - lets you select elements for Masked Fields.
- **Mask editor** - lets you draw or adjust Ignored Zones on a previewed event.

### Needs focus

<img src={liveNoFocusImg.src} alt="Needs focus status badge shown when the pointer is outside the recorder" />

When the pointer leaves the recorded browser, the badge changes to **Needs focus**. The session remains active, but live input is not captured. Move the pointer back over the Live Screen to return to **Live**.

### Replay

<img src={replayImg.src} alt="Replay status and current replay step" />

Displayed while the recorder replays captured steps. The toolbar also shows the current step. All user actions are blocked until replay completes.

### Regenerate

<img src={regenerateImg.src} alt="Regenerate status and current regeneration step" />

Displayed while the recorder rebuilds reference screens for the timeline. The toolbar shows the current step, and all user actions are blocked until regeneration completes.

### Preview

<img src={previewImg.src} alt="Preview status for a selected timeline event" />

Shown when you select an event in the Session Timeline. The toolbar identifies the selected step, the canvas shows its stored screen, and the contextual panel displays event details.

In Preview you can:

- View the screenshot captured for the event.
- Review event properties.
- Edit supported settings, such as **Ignore page structure** for a mouse click.
- Set or adjust [Ignored Zones](/codeless-recorder/ignored-zones).
- Update the expected value of a [Text Checker](/codeless-recorder/text-checker).

You cannot interact with the live page or add new events while in Preview.

## Switching between statuses

| From | To | How |
|------|------|-----|
| Connecting | Live | Automatic - once the first live frame is available |
| Live | Preview | Select an event in the Session Timeline |
| Preview | Live | Close Event Preview or select the active event again |
| Live | Replay | Trigger a [replay](/codeless-recorder/replay-and-regenerate) |
| Live | Regenerate | Trigger a [regenerate](/codeless-recorder/replay-and-regenerate) |
| Replay / Regenerate | Live | Automatic - once the process finishes |

If a tool contains unfinished work, switching away from it opens a confirmation before that progress is discarded.
