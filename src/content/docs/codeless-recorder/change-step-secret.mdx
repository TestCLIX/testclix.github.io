A recorded [Insert secret](/codeless-recorder/insert-secret) or
[OATH](/codeless-recorder/session-oath) step can be repointed at a different stored
[secret](/secrets/overview) without re-recording it.

This is how you repair a step whose secret was deleted, and how you switch a scenario over to a
different account or a rotated key.

## Opening the step's options

Selecting a step in the recorder timeline opens its details panel, which has a **Details** tab and
an **Options** tab. Changing the secret is done on the **Options** tab.

<Steps>

1. Navigate to **Workspace** using the left sidebar menu and locate the scenario.

2. Click the three-dot menu and select **Modify scenario steps**. The scenario opens in the recorder.

3. Select the step you want to change in the timeline.

4. In the details panel, switch to the **Options** tab.

5. Change the secret as described below, depending on the step type.

</Steps>

<img src={secretStepDetailsPanel.src} alt="Step details panel with the Details and Options tabs, showing the Secret section" />

:::note
Modifying scenario steps requires the **Editor** role or higher. See
[Roles & Permissions](/project-management/permissions).
:::

## Insert secret steps

The **Options** tab shows a **Secret** section:

> "Change which stored secret this step pastes during replay."

<Steps>

1. Pick the replacement secret from the picker.

2. Click **"Save secret"**.

</Steps>

The step now references the new secret. Its value is still resolved on the server at run time and is
never shown in the recorder.

## OATH steps

The **Options** tab shows an **OATH secret** section, which starts with *"Change the key this step
authenticates with."* It has the same source dropdown as when
[adding an OATH step](/codeless-recorder/session-oath#how-to-add-an-oath-step).

<Steps>

1. In the source dropdown, choose one of the following:
   - **Text** - enter the new OATH key. It is masked by default, with a show/hide toggle.
   - **Secret** - pick a stored secret from the picker.

2. Click **"Save secret"**.

</Steps>

As when adding an OATH step, a key entered as **Text** is stored with the step, while a stored
secret is only referenced. Prefer **Secret** if you would rather not have the key readable inside
the recording, or if the same key is used by more than one scenario.

## When Save secret is disabled

**"Save secret"** stays disabled until you actually change what the step uses - pick a different
secret, or enter a different key. If the button will not activate, you have not yet changed anything.

## When the step's secret was deleted

If the secret the step used has been deleted, the section shows:

> "The secret used by this step was deleted. Pick a replacement."

Pick another secret and click **"Save secret"** to repair the step. The step card stops showing
**"Secret deleted"** once it points at an existing secret.

:::caution
Deleted values cannot be recovered, and the step no longer shows which secret it used - it displays
**"Secret deleted"** in place of the name. So the portal cannot tell you what to put back: you need
the value, and usually the identity of the old secret, from your own records.

If you have that, [create a new secret](/secrets/manage-secrets#add-a-secret) and select it here.
:::
