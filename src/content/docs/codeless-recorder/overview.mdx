The Codeless Recorder is how you build Website Scenarios in TestCLIX. Instead of writing test scripts, you interact with a real browser streamed from the cloud and the recorder captures every action — clicks, typing, scrolling, navigation — as replayable steps in a timeline.

The recorder runs entirely in the browser. When you start a recording session, TestCLIX launches a remote browser, streams the view to your screen, and records your interactions in real time. The result is a scenario that can be scheduled for automatic monitoring or run on demand.

## Recording a scenario

When the session starts, the recorder opens your target URL and enters [Live mode](/codeless-recorder/recorder-modes#live-focused). From there, you interact with the page as a real user would. Each interaction becomes a step in the [Session Timeline](/codeless-recorder/session-timeline).
