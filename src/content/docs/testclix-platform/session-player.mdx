The **Session Player** is a core functionality that enables the replay of user sessions recorded via the recorder. It is exclusively available for **[Scenario](../website-scenario//overview.mdx)** type tests.

Unlike traditional video players, the Session Player is not time-based but rather **event-based**. It navigates through the chronological history of events registered during the recording process.
