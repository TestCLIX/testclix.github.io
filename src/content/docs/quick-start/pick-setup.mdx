## Choose your setup

Use this page to choose the fastest onboarding path. Both options work without writing code.

If you want a broader comparison of all available test types, including **Website Vitals**, see **[Testing Capabilities](/testclix-platform/testing-capabilities)**.

### If you want to test a real user journey
Choose **[Setup Website Scenario](/quick-start/setup-website-scenario/)**.

This is the best quick start when your next step is to record a realistic browser flow such as:
- Log in &rarr; open dashboard &rarr; create item
- Browse &rarr; add to cart &rarr; checkout
- Fill in a lead form &rarr; submit &rarr; confirmation

You will record the steps in a cloud browser, add checks, and then run the scenario manually or on a schedule.

---

### If you want to monitor server and SSL health
Choose **[Setup Website Availability](/quick-start/setup-website-availability/)**.

This is the best quick start when you need a lightweight setup for technical health monitoring such as:
- Is the site reachable?
- Is the server returning the expected status?
- Is the SSL certificate still valid and configured correctly?

This path is ideal for frequent monitoring and fast alerts when something breaks.

---

### If you want to monitor page performance over time
Choose **[Setup Website Vitals](/quick-start/setup-website-vitals/)**.

Use this when your goal is to track performance quality, including Core Web Vitals and Lighthouse-based thresholds.

This is the right choice when you want to answer questions such as:
- Did the release make the page slower?
- Did layout stability get worse?
- Did accessibility, SEO, or best-practices scores regress?

This gives you the fastest path into vitals monitoring, then links you to the deeper product documentation.

---

## Not sure which one to pick?

A simple starting rule:
- Start with **availability** to get fast monitoring coverage.
- Add a **scenario** to protect your most important user journey.
- Add **vitals** when performance and Lighthouse regressions matter for your key pages.

If you are deciding between test types rather than trying to get started quickly, go to **[Testing Capabilities](/testclix-platform/testing-capabilities)**.
