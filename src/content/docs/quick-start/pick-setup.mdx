## Choose your setup

Use the option below that matches your goal. Both options work without writing code.

### If you want to test a real user journey
Choose **[Setup Website Scenario](/quick-start/setup-website-scenario/)**.

Use this when you need an end-to-end flow such as:
- Log in &rarr; open dashboard &rarr; create item
- Browse &rarr; add to cart &rarr; checkout
- Fill in a lead form &rarr; submit &rarr; confirmation

You'll record the steps in a cloud browser, add checks, and run the scenario on demand or on a schedule.

---

### If you want to monitor basic website availability
Choose **[Setup Website Availability](/quick-start/setup-website-availability/)**.

Use this when you need a lightweight, fast check such as:
- Is the site reachable?
- Does the page load correctly?
- Does the startup path work without errors?

This is ideal for frequent monitoring and quick alerts when something breaks.

---

## Not sure which one to pick?

A simple rule:
- Start with **availability** to get fast monitoring coverage.
- Add a **scenario** to protect your most important user journey.
